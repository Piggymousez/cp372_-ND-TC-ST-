## Overview

โครงการนี้เป็นการวิเคราะห์ข้อมูลยอดขายช็อกโกแลต โดยมีวัตถุประสงค์เพื่อให้ผู้จัดทำได้นำความรู้จากรายวิชา CP372 Data Analytics and Business Intelligence มาประยุกต์ใช้กับข้อมูลจริง ซึ่งช่วยเสริมสร้างทักษะด้านการวิเคราะห์ข้อมูล การนำเสนอผลลัพธ์ในรูปแบบที่เข้าใจง่าย และสามารถต่อยอดในการทำงานด้านธุรกิจในอนาคตได้

- ข้อมูลที่ใช้ (Data) : https://www.kaggle.com/datasets/atharvasoundankar/chocolate-sales

---

# Tool

Colab : ใช้สำหรับทำความสะอาดและเตรียมข้อมูล (Data Cleaning & Preprocessing), สร้างฟิลด์ใหม่

Excel : ตรวจสอบและสำรวจข้อมูลเบื้องต้น วิเคราะห์เบื้องต้นก่อนนำข้อมูลเข้าสู่เครื่องมือ

Tableau : วิเคราะห์และนำเสนอข้อมูลผ่านกราฟและแผนภาพ เพื่อแสดงแนวโน้มและความสัมพันธ์ของข้อมูลได้ชัดเจนยิ่งขึ้น
